    How it works

    A Python pipeline on the server prepares the data, and this site reads the result through an API.

    1. CollectDownload each month's Drug Tariff file from the NHSBSA website and upload it on the Admin page.
    2. CleanThe pipeline standardises product names, pack sizes, categories and prices, converting pence to pounds, and flags concessions.
    3. AnalyseIt calculates month-on-month change and category changes, then saves a SQLite database and dashboard.json.
    4. ExploreThe dashboard updates as soon as processing finishes. The SQLite database can also feed Power BI or Tableau.
